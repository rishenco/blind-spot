# Rampage Peak

A low-poly browser brawl: a topless bodybuilder vs. an angry ram on a mountain summit. Whoever goes off the cliff loses.

**Controls:** mouse — camera · WASD — move · Space — dodge · Left click — kick (only works on a stunned ram) · F — flex

## Dev
```
npm install
npm run dev        # game at /, model viewer at /viewer.html?model=player|ram|world|scene
npm run build
```
Design: [doc/DESIGN.md](doc/DESIGN.md). Gameplay code in `src/game`, procedural models in `src/models`.
